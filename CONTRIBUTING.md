# Contributing

Corrections, questions and proposed changes to the specifications are welcome as issues or pull requests.

1. **License.** By contributing you agree to Section 11 of the Ultrastable License (LICENSE): your contribution is licensed under it, the Licensor may relicense it commercially, and you keep your copyright. Sign off commits (`git commit -s`, Developer Certificate of Origin 1.1).
2. **Scope.** Read [SCOPE.md](SCOPE.md) first. Proposals that add business-plan, legal-filing, marketing or similar material to the core will be redirected to a Capability Pack.
3. **Requirement format.** Normative text uses MUST, SHOULD, MAY with stable IDs (`US-NN-Rnn`); each spec ends with conformance tests and honest BUILT / RUNNING / PLANNED status. Do not label something BUILT without naming the file and a passing test.
4. **No secrets, no personal data, no private business material.**
